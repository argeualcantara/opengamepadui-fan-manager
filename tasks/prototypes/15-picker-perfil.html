Proposed redesign of the Custom Mode profile flow. Validate the interaction before this becomes real Godot code.
1Save moved into the fan region. There's now one "Save" button next to the profile picker, above the fan tabs, instead of a separate save button buried inside a full profile-list panel below the curves. Clicking it saves both fans' curves to whichever profile is currently selected: no extra confirmation when a named profile is already active.

2Profiles moved above the curves. The profile picker is the first thing you see in the Custom Mode area, before the fan tabs and sliders: you pick (or create) a profile, then edit its curves, not the other way around.

3List becomes a picker. Instead of a scrollable list of every saved profile with delete buttons taking up space at all times, it's a single button showing the active profile name. Click it to open a small dropdown to switch profiles (each row still has its own delete ✕) or pick "New profile…".

4New profile only asks for a name at Save time. Picking "New profile…" doesn't interrupt you immediately: it just marks the picker as pending (dashed dot, italic label) and you keep editing curves normally. The name prompt only appears when you click Save with a pending new profile: same overwrite-confirmation as before if you reuse an existing name.
