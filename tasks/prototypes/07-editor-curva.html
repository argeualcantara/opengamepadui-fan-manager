Editor de curva com sliders

Protótipo estático para validar layout, regra de "empurrar" valores acima e o esquema de navegação antes da implementação em Godot (tasks/07-ui-editor-curva-sliders.md). Clique numa linha para focá-la e use ↑/↓ para trocar de linha, ←/→ para ajustar o valor — esse é exatamente o par de eixos que o Godot já mapeia nativamente (ui_up/ui_down para trocar de linha, ui_left/ui_right para o HSlider focado), sem colisão entre os dois.

Cenários

Custom Mode — curva de ventoinha

Não salvo

Protótipo apenas visual — a regra de monotonicidade, o carregamento inicial (BIOS/perfil) e a marca de "não salvo" são simulados em JS, sem CustomCurveEngine real por trás.
